찬양콘티 A4/A3 · 가로/세로 · 여백 5mm · 악보 좌→우 · 작업 내용은 브라우저에 자동 저장됩니다
사용 방법
① 이미지복사 Ctrl+C → ② 이 화면에서 Ctrl+V → ③ 다음 곡도 반복
배치 형식
A4 가로4곡 2+2 · 5곡 3+2 · 6곡 3+3 · 8곡 3+3+2(3면) · 10곡 3+3+2+2(4면)
A4 세로면 나눔은 가로와 같음. 한 줄에 2곡까지라 3곡이 있는 면은 위 2곡, 아래 1곡으로 2줄이 됩니다.
A3 가로4곡 4(1면) · 8곡 4+4(2면) · 10곡 4+3+3(3면)
A3 세로면 나눔은 가로와 같음. 한 줄에 3곡까지라 4곡이 있는 면은 위 3곡, 아래 1곡으로 2줄이 됩니다.
이용사항
사진 넣기붙여넣는 순서대로 자동 번호가 붙습니다. 사진 파일을 끌어놓거나 ‘사진 선택’으로 넣을 수도 있습니다.
카드 사용법사진마다 카드가 생깁니다. 카드에서 곡 제목·메모를 입력하고, ↻ 90° 버튼으로 사진을 돌릴 수 있습니다.
흰 여백흰 여백은 자동으로 잘라서 모든 악보를 같은 높이로 맞춥니다.
파일 저장콘티 파일로 저장은 JSON 파일로만 저장되고, 파일에서 불러오기도 JSON 파일만 열 수 있습니다.
자동 저장작업 내용은 브라우저에 자동 저장됩니다. 페이지를 닫았다 다시 열면 ‘자동 저장본 불러오기’로 돌아옵니다.
